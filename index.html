Mirla: sistema para para archivos, exhibiciones y publicaciones digitales

Mirla es un sistema minimalista diseñado para transformar sitios web estáticos creados con Publii en colecciones interactivas y publicaciones crossmedia. Pensado específicamente para responder a las necesidades de proyectos en humanidades digitales, repositorios independientes y archivos culturales, Mirla permite gestionar y visualizar datos estructurados de manera sencilla a través de hojas de cálculo (CSV), sin la complejidad ni el mantenimiento de bases de datos tradicionales en servidores.

El sistema se articula a través de dos componentes principales que trabajan en sincronía:

  • El Plugin: Un motor ligero que procesa tus metadatos (incluso relaciones complejas entre múltiples tablas), genera automáticamente las páginas individuales para cada elemento del archivo y empaqueta la información para su consumo en el navegador.
  • El Tema: Una interfaz adaptable, accesible y con soporte para modos claro/oscuro, que incluye una biblioteca de componentes web personalizados. Estos componentes te permiten insertar visualizaciones interactivas (mapas, redes, dendrogramas, líneas de tiempo) directamente en la redacción de tus artículos.

Publicaciones crossmedia

Además, el sistema integra nativamente Paged.js. Esto permite que los ensayos, catálogos y narrativas digitales construidos en la web se transformen fluidamente en documentos listos para impresión (PDF), difuminando la frontera entre el repositorio digital y la publicación editorial tradicional. Esta prestación es útil para desarrollar proyectos editoriales ágiles que funcionan en web y en físico.
