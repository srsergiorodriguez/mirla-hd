Guía Práctica: Editor de Datos Mirla

1. Configurar el Protocolo

El protocolo define qué campos conformarán tu colección. Los atributos pid (Identificador único) y label (Nombre legible) son obligatorios y no pueden ser eliminados o modificados en su tipo.

Al añadir nuevos atributos, asegúrate de seleccionar el tipo correcto. Los tipos de datos válidos son:

  • text: Cadenas de texto estándar.
  • number: Valores numéricos (ej. precios, cantidades).
  • date: Datos cronológicos (ej. 2024 o 2024-05-22).
  • link: URLs externas o internas.
  • youtube: ID de video de YouTube o URL para incrustar.
  • image / video / audio: Archivos multimedia asociados.
  • latlong: Coordenadas geográficas ("latitud, longitud"). Se usa para mapas.
  • ref: Referencias cruzadas a otros ítems (usando PIDs separados por comas). Si seleccionas ref, aparecerá un menú secundario para elegir si la referencia apunta a la Colección Principal o a un Grupo Secundario.

2. Ingresar Metadatos

Añade filas en la tabla de Metadatos. Cada fila es un ítem de tu colección. El sistema marcará en rojo cualquier PID que esté duplicado, ya que deben ser estrictamente únicos.

3. Gestión de Imágenes

Para asociar imágenes a los ítems, dirígete a la pestaña "Galería de Imágenes" y carga tus archivos. La aplicación mantendrá los archivos en memoria y buscará coincidencias automáticamente:

  • Imagen Única: Si un archivo tiene exactamente el nombre del PID (ej. OBJ-001.jpg), se asignará automáticamente como imagen principal.
  • Galerías por Carpeta: Si cargas una carpeta cuyo nombre es el PID (ej. carpeta OBJ-001/), todas las imágenes dentro de ella formarán una galería para ese ítem.
  • Asignación Manual: Puedes hacer clic en el botón "+ Img" en la tabla de metadatos para abrir un selector y asignar imágenes manualmente.

4. Crear Grupos Secundarios

Puedes crear tablas relacionales usando el botón "+ Grupo". Por ejemplo, un grupo "Tecnica". Luego, en el protocolo de la colección principal, podrás crear un atributo de tipo ref apuntando a la tabla "Tecnica". Esto conectará automáticamente los ítems.

5. Cargar e Importar

  • Cargar proyecto (JSON): Restaura el estado completo de tus tablas. Importante: Las imágenes no se guardan en este archivo. Tras cargar un JSON, debes volver a cargar tus imágenes en la Galería para reconectarlas.
  • Importar tabla (CSV): Permite importar datos existentes. El sistema detecta automáticamente si el CSV corresponde a un Protocolo (si contiene las columnas 'Attribute' y 'Type') o a Metadatos.

6. Exportación final para Publii

Asegúrate de seleccionar la compresión adecuada en el menú (WebP es altamente recomendado para reducir el peso en sitios estáticos). Haz clic en "Descargar Colección (ZIP)".

Para integrar los datos en Mirla, extrae el contenido del ZIP descargado (los archivos CSV y la carpeta /images). Debes colocar estos archivos y carpetas sin comprimir exactamente en la siguiente ruta dentro de tu repositorio o sitio de Publii:

Publii/[carpeta_de_tu_sitio]/input/media/files/collection/
