Una guía práctica de publicaciones crossmedia con Mirla

Publicaciones Crossmedia

Una publicación crossmedia existe simultáneamente en varios medios... usualmente, uno digital, como un sitio web, y uno físico, como un fanzine. A diferencia del transmedia, en el que cada medio es complementario, el crossmedia implica una redundancia del contenido. Sin embargo, esa redundancia es útil, pues permite jugar con distintas maneras de expresar y circular el mismo contenido; a través de internet y del mano a mano.

Este documento es una guía, pero también una muestra, de Mirla, un sistema para hacer colecciones digitales y publicaciones crossmedia basado en el generador de sitios web estáticos Publii. El documento fue redactado en un entorno web, diseñado con CSS y enriquecido con algoritmos generativos. A continuación, exploraremos paso a paso cómo puedes adaptar tus propios proyectos editoriales para hacer algo similar.

Mirla incluye un sistema integrado basado en Paged.js y p5.js que te permite tomar cualquier contenido web y convertirlo en una publicación lista para imprimir con elementos de arte generativo.

Paso 0. Instalar Publii y el tema de Mirla

Antes que nada, debes instalar en tu computador el generador de sitios web estáticos Publii (https://getpublii.com/) en tu computador. El software es gratuito, de código abierto, y está disponible para Windows, Mac y Linux. Para empezar a trabajar, debes abrir Publii y crear un proyecto de sitio web.

Luego, debes ir al repositorio de Mirla, a la página de lanzamientos o releases (https://github.com/srsergiorodriguez/mirla-hd/releases), y descargar la versión más reciente de mirlaTheme.zip. Luego vas a Publii, haces clic en los tres puntos o la campana de la esquina superior derecha, vas a themes y le das instalar un nuevo tema. Te pedirá que escojas el archivo con el tema, debes indicar la ruta de descarga de mirlaTheme.zip.

Finalmente, debes ir a Site Settings en la barra lateral de Publii y escoger que usaras mirlaTheme para este sitio web. En esa misma barra lateral encuentras también Theme, allí puedes escoger aspectos generales del tema, como el modo de color, la tipografía y otras cosas. Puedes previsualizar el diseño en cualquier momento haciendo clic en Preview your changes, en la barra lateral.

Paso 1. Crear el contenido web

Publii permite crear varios elementos convencionales en un sitio web, páginas, posts, menús, autores, etc. Puedes crear el contenido de tu sitio web como mejor consideres.

Para hacer la página que usaremos como base para la publicación crossmedia, crea una página normal utilizando el editor visual de Publii. Estructura muy bien tu texto utilizando las etiquetas semánticas estándar (Títulos H1, H2, Párrafos, Citas e Imágenes).

Recomendación: El motor de impresión está diseñado para leer estas etiquetas y aplicarles automáticamente el formato de libro (márgenes, saltos de página y notas al pie).

Paso 2. Generar la versión de impresión

En la lista de páginas de Publii, encuentra tu página original y haz clic en Duplicar. Hazlo cuando el contenido esté terminado para que ambas versiones sean idénticas.

En la página duplicada, ve a la barra de la derecha, ve a Other options > Template y selecciona Printable Page Template. Esto le indicará a Publii que esta página duplicada usará un formato distinto, apto para impresión.

Al previsualizar, el diseño web desaparecerá y se mostrarán las páginas físicas, con márgenes, paginación, etc.

Paso 3. Ajustar el diseño de impresión (CSS)

El diseño de la versión física se controla desde el archivo page-print.hbs. Este archivo está en la carpeta del proyecto (usualmente documentos/Publii/sites/[nombre-del-proyecto]/input/themes/mirlaTheme/page-print.hbs). Al editar este código CSS, cambias la forma en la que se presenta el PDF final imprimible sin afectar tu sitio web original.

Algunas cosas clave que puedes y debes editar en este archivo son:

Tamaño de página y tipografía

Al inicio del bloque de estilos CSS encontrarás una sección llamada :root. Aquí se definen las variables maestras de tu fanzine. Puedes alterar las dimensiones del papel (usando pulgadas in, milímetros mm o centímetros cm) y cambiar las fuentes tipográficas por defecto:

:root {
  /* Tamaño de la página (Ej. Media Carta) */
  --page-width: 5.5in;
  --page-height: 8.5in;

  /* Variables Tipográficas */
  --font-body: 'EB Garamond', serif;
  --font-heading: 'Libre Franklin', sans-serif;
}

Márgenes y lomo

Los márgenes físicos del papel se definen directamente usando las reglas @page. Si vas a grapar o encuadernar tu publicación, es importante dejar un margen interior (lomo) más amplio que el margen exterior. Modifica los milímetros en esta sección:

@page :left {
  margin-left: 15mm;  /* Margen exterior */
  margin-right: 20mm; /* Margen interior (Lomo) */
}
@page :right {
  margin-left: 20mm; /* Margen interior (Lomo) */
  margin-right: 15mm; /* Margen exterior */
}

Controlar los saltos de página

A veces quieres forzar que un capítulo nuevo empiece en una página limpia, en lugar de continuar inmediatamente debajo del texto anterior. Para esto, puedes usar unas clases de CSS especiales directamente en el editor HTML de Publii:

  • <h2 class="page-break">Capítulo 2</h2>: Empuja este título a la siguiente página disponible.
  • <h2 class="right-page-break">Capítulo 2</h2>: Empuja el título específicamente a una página derecha (impar). Paged.js insertará una página en blanco si es necesario para lograrlo. Es ideal para iniciar nuevas secciones.

Paso 4. Configurar páginas generativas (arte con p5.js)

Puedes incluir páginas especiales que contengan arte generativo programado con la librería de código creativo p5.js (https://p5js.org/). Así, cada vez que se recarga la página, es posible generar ilustraciones diferentes, lo que le da un aspecto único a los ejemplares impresos.

En el editor de Publii, cambia a la vista de código HTML e inserta un bloque como este en donde quieras incluir una página generativa:

<div class="canvas-page">
  <canvas class="generative-canvas" data-type="mi-portada"></canvas>
  <h1>Título de mi Zine</h1>
</div>

Dentro del div con clase 'canvas-page' debes incluir un canvas con la clase 'generative-canvas'. Además de eso, puedes incluir otros elementos HTML, como títulos o párrafos que se superpondrán al canvas con la imagen generativa.

El attribute data-type es un nombre especial que usarás para distinguir un arte generativo de otro en el código. Para programar el arte, edita el archivo zine.js en la carpeta del proyecto (usualmente documentos/Publii/sites/[nombre-del-proyecto]/input/themes/mirlaTheme/assets/js/zine.js):

case 'mi-portada':
  p.strokeWeight(2);
  p.noFill();
  p.stroke(0); 
  for (let x = 0; x < p.width; x += 50) {
    for (let y = 0; y < p.height; y += 50) {
      if (p.random() > 0.5) p.circle(x, y, p.random(10, 40));
    }
  }
  break;

Paso 5. Exportación e imposición

Una vez que el contenido, los estilos CSS y el arte generativo estén listos, es momento de transformar tu código web en un objeto físico.

Exportar el PDF

Estando en la previsualización de tu página imprimible (donde ves las páginas blancas sobre el fondo gris), abre el diálogo de impresión de tu navegador presionando Ctrl+P (o Cmd+P en Mac). Cambia la impresora destino a "Guardar como PDF".

Para que el archivo quede perfecto, debes realizar dos configuraciones vitales en esa misma ventana (usualmente bajo el botón de "Más opciones"):

  1. Márgenes: Cámbialos a "Ninguno" (None). Paged.js ya calculó los márgenes exactos de tu fanzine; si el navegador añade sus propios márgenes, el diseño se encogerá y se dañará.
  2. Gráficos de fondo: Asegúrate de que esta opción esté activada. De lo contrario, los colores de fondo y las imágenes de tu arte generativo podrían no exportarse.

Guarda el PDF en tu computador.

¿Qué es la imposición o compaginación?

El PDF que acabas de exportar es de lectura secuencial. Es decir, las páginas van en orden numérico (1, 2, 3, 4...). Sin embargo, para imprimir un fanzine físico y doblarlo por la mitad (formato booklet o cuadernillo), las páginas deben reordenarse y emparejarse de una forma muy específica en la misma hoja de papel (por ejemplo, la primera y la última página se imprimen juntas). A este proceso matemático de reordenamiento se le conoce como imposición o compaginación.

Herramientas de Imposición

Paged.js diseña el libro, pero no hace la imposición. Para preparar tu archivo final para la impresora a doble cara, toma tu PDF exportado y pásalo por alguna de estas herramientas especializadas:

  • Spectrolite: Nuestra opción recomendada. Es una aplicación de escritorio visual (Mac/Windows) extremadamente fácil de usar, diseñada específicamente para hacer fanzines y separaciones de color para risografía. Solo arrastras tu PDF y seleccionas la opción de imposición para zines.
  • pdfcpu: Una herramienta de línea de comandos muy ligera pero poderosa, ideal para usuarios que prefieren trabajar desde la terminal.
  • pdfimpose.it o online2pdf: Alternativas rápidas y gratuitas que funcionan directamente en el navegador de internet sin tener que instalar nada.

Tip de impresión: Al momento de imprimir el PDF ya compaginado, si vas a imprimir a doble cara, asegúrate de configurar tu impresora para que voltee la hoja por el "Borde corto" (Flip on short edge). ¡Esto evitará que la mitad de tus páginas queden al revés!
